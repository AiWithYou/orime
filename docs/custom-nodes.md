# カスタムノードの簡易操作

ノード画面で拡張が読み込む相対URLのリソースも、接続先ComfyUIから取得します。

カスタムグラフでは標準レシピのモデル選択を隠し、そのグラフの設定だけを表示します。標準レシピへ戻るには「新規レシピ」を使います。

履歴の画像をクリックすると、現在の画像やマスクを変えずに拡大表示します。「編集に使う」を押したときだけ編集元を差し替えます。拡大表示はEscでも閉じられます。ツールバーの「マスクを隠す」は表示だけの切り替えで、描き始めるとマスク表示に戻ります。

ヘッダーの「画像ツール」から、現在の画像を使って輪郭・線画・深度・ポーズ抽出、画像サイズ変更、余白追加を行えます。処理条件を指定して「キャンバスで開く」を押し、「生成する」で実行します。現在の作業は下書きに残ります。生成モデルの種類に依存しない画像処理なので、量子化モデルで作った画像にも使えます。

接続先のComfyUIが公開する入力仕様から設定欄を作ります。未導入のノードは実行できず、配布元へのリンクを表示します。「接続を更新」で導入後の一覧を取得できます。モデルを使用するプリプロセッサーは、初回実行時に拡張自身が追加モデルをダウンロードする場合があります。深度抽出は小型のViT-Sを初期選択します。

処理の準備中は条件を固定します。接続先の入力・出力仕様が変わり、そのまま接続できない場合は元の作業を切り替えずエラーを表示します。マスク処理の出力は白黒のマスク画像です。

| 拡張 | 簡易画面で扱う用途 | 配布元 |
| --- | --- | --- |
| ControlNet Auxiliary Preprocessors | Canny輪郭、線画、Depth Anything V2、DWPose | [公式](https://github.com/Fannovel16/comfyui_controlnet_aux) |
| KJNodes | リサイズ、余白追加、マスクの拡張・ぼかし | [公式](https://github.com/kijai/ComfyUI-KJNodes) |
| Impact Pack | ワークフロー内のFaceDetailerの主要設定 | [公式](https://github.com/ltdrdata/ComfyUI-Impact-Pack) |
| IPAdapter Plus | ワークフロー内の参照強度と適用区間 | [公式](https://github.com/cubiq/ComfyUI_IPAdapter_plus) |
| Ultimate SD Upscale | ワークフロー内の倍率、タイル、再描画強度 | [公式](https://github.com/ssitu/ComfyUI_UltimateSDUpscale) |
| rgthree | ワークフロー内の標準ウィジェット、ノード画面でのグラフ補助 | [公式](https://github.com/rgthree/rgthree-comfy) |

既存ワークフローは「ノード入力を簡易画面に追加」の用途別ボタンから主要設定をまとめて取り出せます。検索でノード名・入力名を絞り込み、個別に追加・解除することもできます。リンクで制御中の入力はロックされ、グラフの接続は変えません。専用の複合ウィジェットは標準入力として取り出せない場合があるためノード画面で編集してください。

画像ツールは単独の処理グラフを作ります。深度・ポーズ画像を抽出しただけでは生成へのControlNet適用は行いません。適用には生成モデルと互換性のあるControlNetと接続が必要です。FaceDetailer/IPAdapter/Ultimate SD Upscaleは、モデルや検出器を含む配布元のワークフローを先に読み込んでください。任意のモデルへの自動接続や変換は行いません。

各拡張はComfyUIの`custom_nodes`へ導入し、配布元の手順で依存関係を準備してComfyUIを再起動してください。拡張コード・モデルは同梱せず、それぞれの利用条件が適用されます。IPAdapter Plusは配布元で保守のみと告知されています。

追加のPythonパッケージを既存環境と分けて置く場合は、`settings.local.json`の`pythonPath`にそのフォルダーを指定できます。同時起動するComfyUIのPython検索パスに追加されます。
